Aquest repositori de Github preten recollir informació útil per impartir el mòdul de Base de Dades dintre dels Cicles Formatius de Grau Superior ASIX/DAW/DAM.

## Contingut

Aquest repositori conté esquemes de base de dades, exemples de pgsql, i activitats per desenvolupar amb Postgres (testejat fins la versió 15). 

Està estructurat seguint les quatre UFs del mòdul de BD.

* [UF1](UF1) - Introducció a les Bases de Dades
* [UF2](UF2) - Llenguatge SQL-DML i DDL
* [UF3](UF3) - Llenguatge SQL, DCL i extensió procedimental
* [UF4](UF4) - Base de dades Objecte Relacionals
